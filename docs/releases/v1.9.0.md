# v1.9.0 — Reliability & UX

This update focused on making SupplierFlow more dependable for local testing.

## What improved

- Uploading and converting another file without refreshing the page.
- Fixes for unwanted page movement after a refresh.
- More checks for CSV and Excel files.
- Login, logout and temporary account lock tests.
- Tests with two separate accounts.

## Test result

197 automated tests ran: 196 passed and 1 was skipped. The team also checked the main workflow by hand.

This version is approved for **private local testing only**. It is not yet approved to run as a public SaaS service.
